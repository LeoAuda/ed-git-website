Green Bikes
Website for Green Bikes, a fictional bicycle rental company offering affordable and sustainable transport in the city centre. The company provides different types of bicycles, including electric bikes and mountain bikes.
This project is developed as part of a web development assignment, using Git and GitHub for version control.

Technologies
HTML5
CSS3

How to run the website
Clone or download this repository.
Open the project folder on your computer.
Open the index.html file with your preferred web browser.
